# power-insight
Plataforma SaaS de Business Intelligence com IA para geração automática de dashboards e insights.

# 🚀 Power Insight

Power Insight é uma plataforma inteligente de Analytics e Business Intelligence que transforma planilhas Excel em dashboards interativos automaticamente.

O sistema foi desenvolvido para democratizar a análise de dados, permitindo que qualquer usuário envie arquivos Excel (.xlsx, .xls ou .csv) e obtenha visualizações, indicadores e insights sem necessidade de conhecimento técnico em BI.

## ✨ Principais Recursos

* Upload de planilhas Excel e CSV
* Geração automática de dashboards
* KPIs calculados em tempo real
* Gráficos interativos com Chart.js
* Interface moderna e responsiva
* Análise automática de dados
* Detecção dinâmica de colunas
* Insights gerados por Inteligência Artificial
* Compatível com diferentes estruturas de planilhas

## 📊 Visualizações Disponíveis

* Gráfico de Barras
* Gráfico de Pizza
* Gráfico de Tendência
* Indicadores de Receita
* Indicadores de Crescimento
* Métricas de Clientes
* Métricas de Vendas

## 🧠 Inteligência Artificial

O Power Insight identifica automaticamente padrões nos dados enviados e gera interpretações que auxiliam a tomada de decisão.

A plataforma foi projetada para reconhecer diferentes formatos de planilhas, adaptando os dashboards de forma dinâmica para exibir as informações mais relevantes.

## 🛠 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Chart.js
* SheetJS (XLSX)

## 🎯 Objetivo

Transformar dados em decisões estratégicas através de uma experiência simples, moderna e acessível para empresas, analistas e gestores.
